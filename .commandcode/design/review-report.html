// PRIORITY ISSUES
P0

No focus-visible rings anywhere

index.css:393-421 defines hover and active for sidebar buttons, chips, and inputs, but no :focus-visible rule exists in the file. Tab can land on every control with nothing visible.

FIX: add a 2-3px offset focus ring with 3:1 contrast on sidebar buttons, .chip, .btn, .search, and .field inputs
P1

Unnamed icon-only close button

App.tsx:248 and :379 render with no aria-label. A screen reader announces an unlabeled button.

FIX: aria-label="Tutup" on both close buttons
P1

"Magic 30m" is unexplained jargon

App.tsx:195, :219, :322. The primary row action and the save button promise "Magic 30m" with no definition on the surface. The operator must guess what it does.

FIX: rename to the concrete artifact ("Buat Kartu QR") or define it once in the page-header-sub
P2

Card-in-card and row-on-row card stacking

App.tsx:539 nests a .card button inside a .card container (Absensi picker). App.tsx:361-372 stacks one .card per Kegiatan row with hairlines. Both are the spec-sheet default the design language rejects.

FIX: flatten picker rows to plain bordered rows; group Kegiatan into a 2-col grid or one table
P2

Fixed-height shell clips at zoom

index.css:344-351. .admin-shell uses height: 100dvh + overflow: hidden. At 200% zoom or small viewports content can be cut off and unreachable.

FIX: min-height: 100dvh, remove overflow: hidden, let .admin-main scroll
